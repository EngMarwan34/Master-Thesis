# برنامج تعبئة النماذج

يعبّي ثلاثة نماذج (كشف الساعات الإضافية، بدل وجبة، طلب شراء) على نفس قوالب الإكسل الأصلية (الشعار والتنسيق كما هي)، ثم يُخرج PDF جاهز للطباعة + ملف Excel.

## التشغيل
1. ثبّت Python، و LibreOffice (لإخراج PDF؛ بدونه تحصل على Excel فقط).
2. `pip install -r requirements.txt` ثم `python app.py` (أو شغّل `run.bat` على ويندوز).
3. يفتح المتصفح على http://localhost:8000 — اختر النموذج، عبّي الفراغات، اضغط «إنشاء النموذج».

الملفات الناتجة تُحفظ في مجلد `output/`.
القوالب في `templates/`؛ لتغيير قالب عدّل ملف الإكسل أو أعد بناءها بـ `python build_templates.py`.
