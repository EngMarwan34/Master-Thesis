# نظام طلبات قطع الغيار – فرع المدينة

تطبيق ويب لحل مشكلة تشتت طلبات قطع الغيار بين فروع جدة والرياض والخبر، وربطها
برقم طلب الصيانة وكود القطعة والكمية، وتجهيز رسالة الطلب عبر واتساب، وتوثيق
استلام الفني للقطعة في فرع المدينة.

## المزايا

- **ربط كامل**: كل قطعة مرتبطة برقم طلب الصيانة، وكودها، وكميتها، والفرع الذي
  ستصل منه، ونوع المصدر (طلب جديد / سحب من مخزون قائم).
- **تقسيم القطعة الواحدة على عدة فروع**: نفس القطعة يمكن أن تتوزع كميتها على
  جدة والرياض والخبر بنسب مختلفة (مثال: 10 قطع → 3 رياض + 2 جدة + 5 خبر).
- **تجهيز رسالة واتساب تلقائيًا**: من صفحة «مركز رسائل واتساب» يتم تجميع كل
  القطع المطلوبة من نفس الفرع في رسالة واحدة جاهزة للنسخ أو الإرسال المباشر
  (رابط wa.me).
- **مخزون الفروع**: تسجيل القطع المتوفرة مسبقًا في الفروع الثلاثة، مع تنبيه
  عند إضافة قطعة موجودة أصلًا في المخزون، لسحبها بدل طلبها من المورد وتفاديًا
  لبيعها بالخطأ.
- **توثيق الاستلام رقميًا**: تأكيد استلام الفني بالاسم والوقت عند وصول القطعة
  لفرع المدينة، بدل الاستلام بدون أي إثبات.
- **تتبع الحالة**: بانتظار تجهيز الرسالة ← تم الإرسال عبر واتساب ← تم الشحن ←
  تم الاستلام.

## التقنية

- [Next.js](https://nextjs.org) (App Router) + React + TypeScript.
- Tailwind CSS للتنسيق (واجهة عربية RTL).
- قاعدة بيانات SQLite عبر `node:sqlite` المدمجة في Node.js (لا تحتاج تثبيت أي
  محرك قاعدة بيانات خارجي)، محفوظة في ملف `data/app.db`.
- **يتطلب Node.js 22.5 أو أحدث** (بسبب `node:sqlite`).

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

للتشغيل كإنتاج:

```bash
npm run build
npm start
```

قاعدة البيانات ملف واحد (`data/app.db`) يُنشأ تلقائيًا عند أول تشغيل. لعمل
نسخة احتياطية يكفي نسخ هذا الملف.

## طريقة الاستخدام

1. **طلبات الصيانة**: أنشئ طلب صيانة برقمه، ثم أضف له القطع المطلوبة وكمياتها.
2. عند وصول القطع لأحد الفروع، افتح الطلب ووزّع الكمية على الفرع الذي وصلت
   إليه فعليًا (يمكن توزيع نفس القطعة على أكثر من فرع). إذا كانت القطعة متوفرة
   في مخزون أحد الفروع (مسجّلة في صفحة «مخزون الفروع») يظهر تنبيه يقترح
   السحب من المخزون بدل الطلب.
3. من صفحة **مركز رسائل واتساب**: لكل فرع، اختر القطع المطلوب طلبها الآن،
   وسيتم تجهيز نص رسالة موحّد (رقم الطلب + كود القطعة + الكمية لكل بند)، مع
   إمكانية النسخ أو فتح واتساب مباشرة. بعد الإرسال، اضغط «تم الإرسال» لتحديث
   الحالة.
4. من صفحة **استلام القطع**: وثّق شحن القطعة من الفرع (مع رقم تتبع اختياري)،
   ثم عند وصولها لفرع المدينة أكّد الاستلام باسم الفني ووقت الاستلام —
   يُسجَّل تلقائيًا في سجل القطعة.
5. صفحة **الإعدادات** لحفظ رقم واتساب كل فرع (اختياري) لتسهيل فتح المحادثة
   مباشرة من مركز الرسائل.

## ملاحظات وحدود النسخة الحالية

- مصمم حاليًا لمستخدم واحد (بدون تسجيل دخول)؛ يمكن إضافة صلاحيات متعددة
  المستخدمين لاحقًا إذا احتجت إشراك الفني في تأكيد الاستلام مباشرة.
- إرسال رسالة واتساب يتم يدويًا (نسخ النص أو فتح رابط wa.me) وليس عبر
  WhatsApp Business API — حسب المطلوب، لأن الفروع لا تتعامل إلا عبر واتساب
  عادي.
- قاعدة البيانات ملف SQLite محلي؛ عند النشر على استضافة بدون قرص دائم
  (serverless بحتة) يجب استضافته على خادم/حاوية بقرص دائم حتى لا تُفقد
  البيانات بين الطلبات.
