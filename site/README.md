# موقع تعبئة النماذج

موقع ثابت (بدون خادم) يعبّي: كشف الساعات الإضافية، بدل وجبة، طلب شراء. معاينة مباشرة + تنزيل PDF و Excel + طباعة.

- **التشغيل محليًا:** افتح `index.html` في المتصفح مباشرة.
- **النشر:** ارفع مجلد `site/` كما هو على أي استضافة ثابتة (GitHub Pages، Netlify، …).
- المكتبات (ExcelJS و html2pdf) موجودة في `lib/` فلا يحتاج إنترنت.
- البيانات المُدخلة تُحفظ في متصفحك فقط.
- لتحديث القوالب من ملفات إكسل جديدة: `python tools/build_assets.py <ملف1.xlsx> <ملف2.xlsx>` (من جذر المشروع).
