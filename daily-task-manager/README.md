# مدير المهام اليومي

تطبيق ويب بسيط (صفحة واحدة، بدون خادم أو إنترنت) لإدارة مهام اليوم على فترتين، مبني خصيصًا لحل مشكلة نسيان المهام.

## طريقة التشغيل

افتح ملف `index.html` مباشرة في المتصفح (دبل كليك)، أو استضفه على أي استضافة ثابتة (GitHub Pages مثلًا). كل البيانات تُحفظ محليًا في المتصفح (`localStorage`) — لا حاجة لحساب أو إنترنت.

> ملاحظة: لتصلك تذكيرات المتصفح (Notification) حتى لو كانت الصفحة في الخلفية، افتح تبويب "الإعدادات" واضغط "تفعيل إشعارات المتصفح". النافذة المنبثقة داخل الصفحة تعمل دائمًا كخيار احتياطي حتى بدون هذا الإذن، طالما الصفحة مفتوحة.

## المزايا المطبّقة

- **قائمة مهام بسيطة بدون تصنيفات/مشاريع**، لكل مهمة اسم ووقت متوقع (بالدقائق) يحدده المستخدم يدويًا.
- **تعليم "تم الانتهاء"** بضغطة واحدة (checkbox).
- **التأجيل**:
  - المهام غير المكتملة بنهاية اليوم تنتقل تلقائيًا لليوم التالي (تُحسب "تأجيل" في التقارير).
  - زر تأجيل يدوي (⏭️) لتأجيل أي مهمة بنفسك قبل نهاية اليوم.
- **التذكير بالفترتين**:
  - نافذة منبثقة داخل الصفحة + إشعار متصفح (اختياري) عند بداية كل فترة، تعرض مهام تلك الفترة.
  - أوقات الفترتين قابلة للتعديل من تبويب "الإعدادات" (افتراضيًا: 9:00–13:00 و1:00–5:00 عصرًا).
- **حساب الوقت**:
  - يظهر الوقت المتوقع بجانب كل مهمة.
  - حساب تلقائي للوقت المتبقي في كل فترة (مدة الفترة − مجموع أوقات مهامها).
  - تنبيه أحمر عند تجاوز مجموع أوقات المهام للوقت المتاح في الفترة (تحذير ازدحام الجدول).
- **نسبة الإنجاز والتقارير**:
  - نسبة إنجاز اليوم تظهر أعلى الشاشة الرئيسية (مثال: 5/8 = 62%).
  - تبويب "التقارير" يعرض ملخص آخر 7 أيام (منجزة / مؤجلة / نسبة الإنجاز لكل يوم) وملخصًا أسبوعيًا، بدون أي تصدير لملفات — كل شيء داخل التطبيق.

## هيكل الملفات


## ملاحظات تقنية

- التطبيق من جهة العميل بالكامل (Vanilla JS)، بدون مكتبات أو أدوات بناء.
- البيانات محفوظة في `localStorage` على نفس الجهاز/المتصفح فقط.
- فحص بداية الفترات والتأجيل التلقائي لنهاية اليوم يعملان طالما الصفحة مفتوحة (يُنفَّذ فحص كل 20 ثانية)، والتأجيل التلقائي يلحق أيضًا بأي أيام فاتت إن لم يُفتح التطبيق في وقتها.
