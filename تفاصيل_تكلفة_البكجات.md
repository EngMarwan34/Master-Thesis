Methodology | المنهجية:
Cost values are not taken as fixed numbers from a single source. Each cost item uses a literature/market range as a benchmark, then a selected value is chosen within that range using engineering estimation. The selected value is justified based on retrofit boundary, building size, repeated work, system complexity, and whether the measure is a partial upgrade or full replacement.

لا يتم أخذ القيم كأرقام ثابتة من دراسة واحدة، بل يتم استخدام مدى من المراجع/السوق، ثم اختيار قيمة داخل هذا المدى بناءً على تقدير هندسي يراعي حدود العمل، حجم المبنى، تكرار الأعمال، تعقيد النظام، وهل التحسين جزئي أم استبدال كامل.
